# Mechanical Design – González Manuel

This repository contains the complete 3D CAD modeling and 2D technical documentation for the **González Manuel** mechanical design project, developed in **Autodesk Inventor 2026**.

## Folder Contents

| File | Format | Description |
| :--- | :--- | :--- |
| `González_Manuel.ipt` / `.iam` | Native Inventor | Original parametric 3D CAD model/assembly file. |
| `González_Manuel.stp` | STEP (ISO 10303-21) | Neutral 3D solid geometry for cross-platform CAD compatibility and CAM/CAE workflows. |
| `González_Manuel.dwg` | AutoCAD DWG | 2D vector drawing export for CAD drafting and CNC/laser cutting workflows. |
| `González_Manuel.pdf` | PDF | Complete 2D technical manufacturing blueprint including orthographic views, sections, and tolerances. |

## Software & Standards

* **CAD Software:** Autodesk Inventor 2026
* **3D Exchange Standard:** STEP AP214 / ISO 10303-21
* **Units:** Millimeters (mm)
